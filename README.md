# Coaster Lab

A 3D roller coaster simulator and park game in a single HTML file (three.js 0.160 from a CDN). Open the HTML file in a
browser (made for iPhone, works on desktop).

| File | What it is |
|---|---|
| `coaster_lab_v9_0.html` | **Current version**: Track Builder 5.0 (three levels, one card per problem, gentler repairs, starter blueprints), sketches that close into circuits, ride fares that matter, guest speech bubbles |
| `coaster_lab_v8_6.html` | The previous version, kept untouched as a backup |
| `coaster_lab_v8_5.html` | The version before that, also untouched |
| `CHANGES-9.0.md` | What changed in 9.0 and why, what was measured, known limits, next steps |
| `CHANGES-8.6.md` | What changed in 8.6, an iPhone test checklist, leaderboard ideas |
| `PLAN-8.6.md` | The plan written before building 8.6 |
| `tests/` | Headless browser tests (see `tests/README.md`) |

Saves made by 8.5 and 8.6 open in 9.0 unchanged. All three files use the same browser storage, so going back to an older
file also works.
