# Coaster Lab

A 3D roller coaster simulator in a single HTML file (three.js 0.160 from a CDN). Open the HTML file in a browser
(tested on iPhone).

| File | What it is |
|---|---|
| `coaster_lab_v8_7.html` | **Current version**: adds 👑 VIP ($2 once: 3 golden VIP coasters + VIP colours), paid with Stripe |
| `coaster_lab_v8_6.html` | The previous version, kept untouched as a backup: 🪐 Gravity Lab, 💥 Disaster Mode, 🧬 Evolve, 📅 Daily Challenge |
| `coaster_lab_v8_5.html` | An older backup |
| `CHANGES-8.7.md` | What changed in 8.7, how VIP payments work, and the steps to go live |
| `supabase/functions/` | The two small VIP backend functions (Stripe webhook + VIP status/restore) |
| `CHANGES-8.6.md` | What changed in 8.6, known limits, an iPhone test checklist, leaderboard ideas |
| `PLAN-8.6.md` | The plan written before building 8.6 |
| `tests/` | Headless browser tests (see `tests/README.md`) |
| `trailer/` | The 47-second Coaster Lab 8.6 trailer project (Remotion), see `trailer/README.md` |
