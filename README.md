**A 3D roller coaster simulator and theme park game that runs in one HTML file.**
Ride and build coasters, run a park, and share your designs. Made for iPhone, works on desktop.
Built with [three.js](https://threejs.org/) 0.160 (loaded from a CDN). No install and no build step are needed to play.

## Play it

Download the newest file from `builds/` and open it in Safari or Chrome. That's it.
Online features (park sharing, accounts, cloud saves) need the page to be served over `https://`; everything else works offline.

## Working on it

```bash
node build.mjs --check                                  # rebuild 10.1 from src/v10 and syntax-check it
node tools/ci/check-html-syntax.mjs builds/*.html       # syntax-check any finished build
python3 tools/ci/secret-scan.py                         # make sure no secret is about to be committed
cd tests && npm install && npx playwright install chromium && npm test   # full regression run (long)
```

Details: [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) · testing: [`docs/TESTING.md`](docs/TESTING.md) · security: [`docs/security/HARDENING-2026-11-27.md`](docs/security/HARDENING-2026-11-27.md)

## Branches

| Branch | Purpose |
|---|---|
| `main` | What is released (or ready to release). Updated only by pull request from `develop`, `release/*` or `hotfix/*`. |
| `develop` | Integration branch. Every feature and fix lands here first. |
| `feature/*` | Gameplay work in progress — `feature/ride-challenges`, `feature/vip-pack-8.7` |
| `chore/*`, `docs/*` | Tooling and documentation — `chore/review-squad`, `docs/branding` |
| `project/*` | Unrelated projects waiting for their own repository — `project/neon-arcade`, `project/cerealsquad1-dashboard` |
| `fix/*`, `release/*`, `hotfix/*`, `test/*`, `experiment/*` | See [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Full map, history of every old branch name and the owner checklist: [`docs/REPOSITORY.md`](docs/REPOSITORY.md).

## Team

Coaster Lab is directed by its owner (@wut41) and built with several AI collaborators: ChatGPT (technical direction),
Claude (lead development and repository), Gemini (independent QA), Replit (testing) and others. AIs do not share
context automatically; the owner passes work between them, so **every change goes through a pull request with a clear description**.
