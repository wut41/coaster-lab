# Coaster Lab

A 3D roller coaster simulator in a single HTML file (three.js 0.160 from a CDN). Open the HTML file in a browser
(tested on iPhone).

| File | What it is |
|---|---|
| `coaster_lab_v8_6.html` | **Current version**: adds 🪐 Gravity Lab, 💥 Disaster Mode, 🧬 Evolve and 📅 Daily Challenge |
| `coaster_lab_v8_5.html` | The previous version, kept untouched as a backup |
| `CHANGES-8.6.md` | What changed in 8.6, known limits, an iPhone test checklist, leaderboard ideas |
| `PLAN-8.6.md` | The plan written before building 8.6 |
| `tests/` | Headless browser tests (see `tests/README.md`) |
